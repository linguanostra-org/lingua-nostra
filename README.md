# Lingua Nostra

Outils libres pour le provençal en graphie mistralienne : lexique pour claviers et correcteurs orthographiques, conjugueur, dictionnaire bilingue provençal-français outils de traitement automatique du langage et code du modèle de langue Lou Pichoun.

Porteur : LINGUA NOSTRA SASU (SIRET 108 870 809 00010). Site : https://linguanostra.org

## Contenu prévu

- `lexique/` : scripts de construction du lexique monolingue provençal (formats Hunspell, Windows, Android).
- `conjugaison/` : conjugueur selon les règles du Conseil de l'Écrit Mistralien.
- `dictionnaire/` : chaîne de construction du dictionnaire bilingue servi sur linguanostra.org.
- `tal/` : outils de traitement automatique du langage pour le provençal (constitution et nettoyage de corpus, segmentation, normalisation en graphie mistralienne, évaluation).
- `lou-pichoun/` : code d'entraînement, d'évaluation et de service du modèle de langue Lou Pichoun. Les poids du modèle seront publiés sur Hugging Face.

Lingua Nostra publie ici, à sa discrétion, le plus grand nombre possible de ses outils.

Les données sources soumises à droits restent hors du dépôt ; seuls le code et les données dont la licence le permet y sont publiés.
